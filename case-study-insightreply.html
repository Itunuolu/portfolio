InsightReply — AI Comment Assistant

A shipped AI-powered Chrome extension that helps professionals write thoughtful, relevant LinkedIn comments by analysing only the post they deliberately select, then generating editable suggestions across different tones and lengths.

01 · Executive summary

Make LinkedIn engagement faster without turning it into autopilot.

Professionals often know they should engage consistently on LinkedIn, but writing a useful comment takes time. Generic AI replies create another problem: they can sound repetitive, detached from the post, or overly automated.

InsightReply was designed around a tighter product principle: AI should assist the user at the moment of intent, while the user keeps final control. The extension adds an AI Comment action beside LinkedIn posts, reads only the post the user selects, generates three relevant suggestions, and lets the user edit, copy or insert the preferred response before posting it manually.

My role: end-to-end product strategy, requirements, UX workflow, AI interaction design, delivery and release direction for the Chrome extension product.

02 · Product challenge

Useful AI comments require context, control and trust.

Context problemGeneric comment generators produce shallow responses when they do not understand the actual post.
Workflow problemCopying a post into a separate AI tool breaks the natural LinkedIn engagement flow.
Trust problemUsers need to know what content is read, what is sent to AI and whether anything can be posted automatically.

Product objective

Reduce the effort required to create thoughtful LinkedIn comments while keeping the interaction selective, transparent and user-controlled.

03 · Product decisions

Selective by design, not feed-wide by default.

Deliberate selection

  • InsightReply does not read the whole feed.
  • Content is extracted only after the user clicks the AI Comment action on a specific post.
  • The selected post is kept in session storage for the active workflow.

Choice before generation

  • Six comment tones.
  • Three response lengths.
  • Optional perspective input for additional context.
  • Three suggestions generated at a time.

User-controlled output

  • Edit or copy any suggestion.
  • Regenerate when the response is not right.
  • Insert into the same LinkedIn post editor.
  • Never submit or press Post automatically.

Safer insertion

  • If the comment box already contains text, the user chooses Replace, Append or Cancel.
  • The workflow preserves the user's ability to review the final wording before publication.

The side panel keeps the task focused: preview the selected post, choose tone and length, generate suggestions, refine the best option, then insert it back into LinkedIn. The user remains the final decision-maker throughout the flow.

Browser-native UX with a validated AI backend.

Backend & AI

Shared contracts

A shared package contains the Zod schemas and message contract used by both the extension and backend. That keeps request and response validation aligned across the browser and server sides.

06 · Privacy by design

Limit collection to what the feature actually needs.

The product deliberately avoids profile crawling and whole-feed reading. Only the selected post and the user's chosen preferences are sent to the backend for generation. The extension's source describes no database, no retention and no automatic posting.

Design principle: minimise access, make the trigger explicit, keep posting manual and preserve user review before anything becomes public.

07 · Validation

Test the workflow, not only the interface.

The repository includes unit tests across shared schemas, API logic and extension behaviour, plus a Playwright browser-level smoke test covering button injection, post extraction and comment insertion in Chromium.

Post extractionVerify the selected LinkedIn post is captured correctly.

Comment insertionExercise the browser flow through to the LinkedIn editor.
